# 多巴胺口算 — 公开版说明书

多巴胺口算（ドパドリル／Dopa Drill）是一款每解一道题，吉祥物的动作、画面演出和音乐就随之增强的浏览器游戏。本书面向玩家、家长以及对开发与改造感兴趣的人，说明当前实现的行为。数值今后可能随调整而变化。

## 1. 概述与设计理念

目标是让孩子每天坚持练一点计算，并能看到自己相比过去的成长。基础题超时也能继续做，做完全部即得 100 分，没有游戏结束。

答错会提示「差一点」，可以重新输入。已获得的星星、奖杯和演出不会因失败或缺席被收回。连续记录有补签机制来衔接休息日；成长对比只展示有进步的项目。奖励全部由达成条件解锁，没有抽签和内购。

界面提供中文、英文和日文，面向小学生的计算练习和成年用户。以手机竖屏为主，也可以用电脑的鼠标和键盘操作。无需注册账号。记录按浏览器分开保存，不与其它设备自动同步。

### 1.1 界面语言

中文是源语言，也是默认语言。首次启动时，日语浏览器显示日语，其余一律中文；检测到的语言不会自动写入设置，之后可在「设置 → 语言」中切换（中文／English／日本語），选择保存在设备上，切换时重新加载应用。若设备上已有旧版（日语版）存档且未选择过语言，同样按浏览器语言处理，日语用户不受影响。

界面文案以中文字符串为查找键（gettext 风格），`app/js/lang/ja.js` 与 `app/js/lang/en.js` 提供翻译，缺失的键回退为中文。`tools/check-i18n.mjs` 校验两个语言包的完整性。切换语言后，旧语言保存的复习题、时间胶囊等「保存的题目对象」在显示时会改写为当前语言的标题与答案格式（题面网格中的个别词语除外），存储本身不会被修改。

## 2. 画面与流程

### 2.1 画面一览

| 画面 | 内容与主要操作 |
| --- | --- |
| 标题 | 标志、多巴奇、我的等级、其正下方的复习与无尽挑战、1〜6 年级、技能树、奖杯、收藏、成长、任务、日历、设置、？ |
| 练习 | 题目、输入的格子、专用数字键盘、答对数、差一点次数、计时、多巴、连击、进度显示、静音 |
| 基础结算 | 100 分、用时、一次答对率、多巴、成长・技能・任务的结果。达成条件时的加时挑战、重做错题、再来一次、返回标题的操作 |
| 最终结算 | 含加时挑战的得分与多巴、答对数、差一点次数、任务、重做・返回标题的操作 |
| 无尽结算 | 最高波次、答对数、得分、多巴、技能结果。再来一次・返回标题的操作（终点页，不承接加时挑战） |
| 技能树 | 前置关系、解锁・练习・掌握状态、星星、生锈、技能说明与练习、删除部分记录 |
| 奖杯 | 按分类・系列展示的成就、获得日期、条件与奖励、筛选、即将达成的成就 |
| 收藏 | 已解锁演出的试看・试听，按类别固定或随机 |
| 成长 | 这周练了多少、会了什么、还记得吗、哪里卡住、坚持、下一步。只读，可打印，「下一步」可直接进入该技能的练习 |
| 设置 | 题目数量、声音、音量、动效强度、自动演示、全部重置、语言 |

通常按「标题 → 基础题 → 基础结算 → 可选的加时挑战 → 最终结算」进行。复习到基础结算为止，无尽挑战从标题开始、在无尽结算结束。结算画面的操作按钮固定在下端，即使成长记录增多也不影响下一步操作。

### 2.2 首次引导与「？」帮助

首次启动显示 5 页引导，依次是：介绍、我的等级、按年级、技能树、推荐我的等级。设置按钮下方的「？」可以重新显示 9 页说明：在首次的 5 页之外，额外加入无尽挑战、奖杯、收藏、成长四页，顺序与标题页上的排列一致（无尽挑战紧跟我的等级，成长排在收藏之后）。复习不在其中——它的按钮在有错题要复习之前是隐藏的，而引导对隐藏目标会拿到零尺寸的选框。

引导用聚光灯照亮说明对象，必要时自动滚动。说明文字显示在独立的卡片上，多巴奇通过移动、指向和表情来引导，但台词不会以多巴奇的口吻显示。最后一页指向「我的等级」和「？」，如果两者无法同时收进画面，卡片内会显示相同的问号图标。

通过「下一步」「上一步」「跳过」以及最后一页的「开始！」操作。Enter 和右方向键是下一步，左方向键是上一步，Escape 是跳过，Tab 在引导内循环焦点。点击暗幕不会关闭，引导期间背景按钮不可操作。

无论看完还是跳过，都会保存为已显示。首次引导之后依次处理：补签锤、登录奖励、奖杯通知。全部重置后会再次显示首次引导。演示中和部分用于验证的 URL 参数下不自动显示。

## 3. 模式

### 3.1 我的等级

首次是「实力测试」。按年级、前置关系深度排序逐题推进，一次答对即把该题技能及其前置技能一起标记为掌握并给 ☆1。移动幅度初始为 6，答对后把当前幅度乘以 1.3 向上取整（最大 12），答错后减半向下取整（最小 1）。答错后会退回到最后一次一次答对位置之后的范围。完成基础题后标记为已测。

之后按前置深度、年级、技能定义顺序选题。从已掌握的末尾 6 个技能中选复习题，复习名额为 `min(候选数, max(1, round(题数 × 0.3)))` 道。生锈技能优先，其余从候选中随机选择。没有已掌握技能时复习名额为 0。

其余题目按顺序重复已解锁・未掌握的前 4 个技能。全部掌握时从所有已掌握技能中选择。加时挑战从尚未掌握候选的末尾 3 个技能中选，没有时用已掌握技能的末尾 3 个。实力测试之后的加时挑战从未掌握候选的开头选择。

### 3.2 按年级

无论解锁状态如何，从所选年级的技能出基础题。按前置浅到深的顺序加随机抖动出题。解答结果同样计入通常的熟练度。

加时挑战前 6 题重复该年级技能列 `floor(技能数 × 0.55)` 之后的部分。第 7 题起切换到下一年级开头最多 4 个技能。6 年级继续重复本年级后半部分。

### 3.3 练习

从技能树中选择已解锁的技能练习。已掌握的技能从说明画面开始练习。基础题是该技能，加时挑战从以该技能为直接前置的已解锁技能中选。没有候选时继续用同一技能。

按年级和练习中，满足条件的时间胶囊可能替换基础题中的 1 道。这道题可能超出指定年级、技能的范围。

### 3.4 复习

把含错答的题目做完时，题目本身最多保存 40 道。以题目标题与算式为标识去重。中途放弃的未完成题不会加入。

从标题和结算的重做按钮开始。从已保存列表的末尾，按设置题数与 10 的较小者为上限选取。从结算按钮开始时，不只限本次的错答，而是使用此前积累的列表。

一次答对的题从列表删除，再次答错的保留。全部做完得 100 分，没有加时挑战。同样计入通常的成长记录、熟练度和任务。

### 3.5 无尽挑战

从标题页进入。三条命，**错一格扣一条**（不是错一题），命尽即结束。答对 10 题回一条命，上限 3 条，回满后不再累积。不设目标时间，计时只累计已用时间；单格时限沿用连击时限，超时不扣命、只断连击。

难度用**出题范围**上升，不是加速。波次从 1 起，每 5 道**一次答对**升一波；1〜2 波出一、 3〜4 波出二年级，依此到 6 年级封顶。因为升波只认一次答对，「打得更远」等价于「算得更准」，靠猜推进不了。

封顶后从已解锁的 4 年级以上技能中交错抽取，并优先未掌握与生锈的技能。始终只出已解锁的技能；当前年级尚未解锁时回退到已解锁的技能，不会卡住。

演出强度随波次上升，并**有界**：`E = 1 + 0.6 × (1 − e^(−(波次−1)/9))`，第 1 波为 1.0，第 20 波为 1.53。离散等级另由波次直接给出：`tier = min(16, 10 + floor((波次−1)/2))`——基础集走完的第 10 档是无尽模式的起点，此后每 2 波升 1 档，第 13 波到顶 16 档。得分沿用加时挑战的递增（第 k 题为 `10 + 5k`），多巴走自己的不收敛曲线（见 §5.2）。均无上限。

结算为终点页，只有「再来一次」与「返回标题」，不承接加时挑战。记录写入历史（含达到的波次），计入成长统计、熟练度、星星、任务与奖杯；**当天的「最高分」仍以基础模式的 100 分制为准**。

标题页的无尽按钮下有一行小字：首次显示规则（「3条命・答错扣命・每10题回命」），玩过之后改为显示最高波次。

### 3.6 自动演示

设置中的「▶ 自动演示玩法」会开始自动操作。从全部技能中选题，按易到难排列，加时挑战从 4 年级以上的技能中选择。使用与普通游玩相同的输入、判定和演出，也会答错。基础题答错题数的上限为 `floor(题数 × 0.2)`。

基础、加时、最终结算走完一圈后回到标题并解除演示。点击或按键也能结束。开始后 600ms 内的点击会被忽略。演示成绩不计入历史、熟练度、复习和成长统计，也不推进任务和奖杯。回到标题后会执行正常的登录处理。

固定选择的演出在演示中同样使用，随机的类别从已解锁项中选择。URL 的 `?demo` 是与该自动操作不同的功能。

## 4. 一局练习与输入

### 4.1 基础题与加时挑战

题数为 6、10、14 道，默认 10 道。基础目标时间为 `ceil(题数 × 18 ÷ 10) × 10` 秒：6 题 110 秒、10 题 180 秒、14 题 260 秒。超时也能继续，不扣分。基础的经过时间从开始练习到完成为止，包含题目切换。

「答对」是解到最终解的题数，「差一点」是输入的数字与当前格子不符的次数。「一次答对」指包括中途输入在内从未答错的题。基础一次答对数除以题数达到 0.8 以上即可选择加时挑战。

加时挑战默认 90 秒。开始处理时以当前时间加 90,000ms 与导入用 900ms 设定截止时刻。不是从首次可输入时刻起保证 90 秒，题目切换期间计时也在走。确认对话框期间暂停。时间到即确定得分并进入最终结算。未完成的题不计分，但已答对格子上增加的多巴保留。

### 4.2 数字的输入

用专用数字键盘和电脑数字键逐位输入，即刻判定。没有确认按钮。正确的位会保留，错误的数字会被下一次输入替换。退格键删除当前的错误数字，不会撤销已答对的位。

手机上会按含浏览器操作栏的可视区域调整题目留白和键盘高度。包括 0 和删除键在内的最下排位于底部安全区之上，画面尺寸变化时题目文字大小会重新计算。

| 题目形式 | 输入顺序与自动显示 |
| --- | --- |
| 横式算式 | 从答案的最高位开始输入 |
| 横式带余除法 | 先商后余数 |
| 加减竖式 | 从最低位开始。进位、退位的辅助数字自动显示 |
| 乘法竖式 | 部分积从右往左输入，有多个部分积时总和也从右往左输入 |
| 除法竖式 | 商的最高位、减完的余数、下一位商的顺序。积、落下的数字、最后的余数 0 自动显示 |
| 小数 | 小数点自动显示，只输入数字 |
| 分数 | 先分母后分子。带分数按整数部分、分母、分子的顺序 |
| 比・字母式・近似数・百分数 | 从指定空位的最高位开始输入 |

分数按预设的作答形式判定。3 年级的同分母分数保持原分母，接受不约分的答案。其余分数计算使用生成的最简分数或带分数形式（国际写法，如 `2 1/3`）。不是自由输入等价表达再判定的方式。

### 4.3 错答与提示

答错的数字使用紫色虚线框。同一格错答 2 次时，若参照数字已定义则高亮并指向它。第 3 次起显示计算过程或乘法口诀等提示。提示中可能包含相当于答案的数值。

答错会把连击清零，但不扣分、不减少多巴，演出阶段和背景音乐保持不变。为让错答音更清晰会暂时压低背景音乐，配合弹跳的音效和多巴奇恢复的表演。

## 5. 得分・多巴・连击

### 5.1 得分

基础完成为 100 分。把加时挑战已完成的题数从 0 记为 `k`，该题的加分为 `10 + 5 × k` 分。完成 `n` 道加时题的总分为：

```text
100 + 10 × n + 5 × n × (n − 1) ÷ 2
```

5 题 200 分、10 题 425 分、15 题 775 分、23 题 1595 分、30 题 2575 分。得分没有固定上限。没有基于连击、答题速度或差一次次数的倍率和扣分。

### 5.2 多巴的计算

多巴是演出的数值，与得分无关。内部值 `L` 为常用对数，显示值的原始量为 `10^L`。开始练习时 `L = 0`。

基础的基准曲线为 `B(f) = 2.3 × clamp(f, 0, 1)^1.15`，加时的基准曲线为 `X(n) = 2.3 + 3.0 × (1 − exp(−n / 10))`，无尽的基准曲线为 `Y(n) = 3.3 × ln(1 + n / 2)`。

设基础总题数为 `N`，已完成的题数从 0 记为 `q`，当前题的作答格数为 `m`，本次答对的格从 1 记为 `s`，则该次输入的基准增量为 `B((q + s/m)/N) − B((q + (s−1)/m)/N)`。设加时已完成题数为 `k`，每格基准增量为 `(X(k+1) − X(k))/m`；无尽同样，但用 `Y`。

注意 `Y` 是**这一局的累计值本身**（`Y(0) = 0`），不是叠加在基础曲线上的偏移，所以屏幕上显示的数就是 `Y(已答对题数)`。

答对时先把连击数 `c` 加 1，再按下面公式反映本次输入：

```text
倍率 M(c) = 1 + (2 − 1) × min(1, max(0, c) / 20)
新的 L = min(上限, L + max(0.003, 基准增量) × M(c))
```

10 连击 1.5 倍、20 连击以上 2 倍。上限按模式取值：基础与加时为 `9.08`（显示值 `10^9.08`），无尽为 `30`——后者是兜底而不是目标，满连击跑 120 题也只到 27。由于增量有 0.003 的下限，实际到达值并不只由基准曲线终点决定。首次答对即 1 连击 1.05 倍；加时开始时连击清零，多巴继续累计。

显示时不足 1 万的部分四舍五入为整数，之后附加「万」「亿」等中文数量单位（英文用 K、M、B 等缩写）。单位内的值不足 10 时显示到小数第 1 位，10 以上显示截断的整数。到达 100、1000、1万、10万、100万、1000万、1亿时有节点的演出。基础与加时不达兆；无尽模式的单位持续推进，但节奏很慢。连击（20 格后 ×2）能把它加快一倍以上：有连击时 万 第 17 题、亿 第 96 题、兆 第 388 题、京 第 721 题；一直断连击则 万 第 46 题、亿 第 819 题。一次不失手的实测对局中，60 题为 830 万、300 题为 899 亿，万 与 亿 分别在第 19 与第 106 题到达（实战比模型再慢一成）。兆 需要约 400 题不失手，属于长跑目标而非一局之内的事。

### 5.3 连击的时间与显示

每个正确的作答格加 1 连击，跨题累计。2 连击以上显示，20 连击以上显示「多巴×2 MAX」。答错或超时清零。不过当前实现中 1 连击的状态不参与超时判定。

年级 `g` 的普通格时限为 `3000 + 600 × (g − 1)` ms，题目第一格加 2500ms。年级限制在 1〜6，未知时按 3 处理。

| 年级 | 普通格 | 题目第一格 |
| --- | --- | --- |
| 1 | 3000ms | 5500ms |
| 2 | 3600ms | 6100ms |
| 3 | 4200ms | 6700ms |
| 4 | 4800ms | 7300ms |
| 5 | 5400ms | 7900ms |
| 6 | 6000ms | 8500ms |

时限在接受输入的时刻设定，题目切换和确认对话框期间不消耗。剩余时间条不足 30% 时高亮。10、20、30、50、75 连击以及 100 以上每 50 连击都会大型庆祝。5 连击以上中断时短暂显示结束的数字。

## 6. 出题范围与技能树

### 6.1 范围与生成

计算共分 58 项技能。按年级为：1 年级 8、2 年级 13、3 年级 14、4 年级 10、5 年级 8、6 年级 5。系统分为「加与减」「乘与除」「小数·分数」「其他」四类。全部技能的名称、标识、前提和生成条件见 `docs/curriculum.md`。

范围是四则计算、带中途输入的竖式、小数、分数、近似数、因数・倍数、运算顺序、百分数、相等的比、字母的值。不出图形、测量、统计图、应用题和汉字数字输入。

按技能条件每次以随机数生成。用最近 24 道题的签名与本次练习内的已出签名避免重复。由于候选生成有重试上限，候选较少的技能可能出现重复。时间胶囊与复习是复现同一题目的例外。

### 6.2 显示与解锁

每个系统分 2 列共 8 列显示，窄屏可纵横滚动。优先按年级排序，5、6 年级排在 1〜4 年级之下。前置关系线绕开其它节点，同一列相邻不代表有依赖。

没有前提的技能最初即解锁，前提有多个时需要全部掌握。状态区分未解锁、新技能、练习中、已掌握。通常的掌握条件是：至少 6 题记录，且最近 6 题中 5 题以上一次答对。已掌握的技能答错也不会回退。实力测试的一并赋予是该次数条件的例外。

### 6.3 技能的星星

掌握后依次获得 ☆1〜☆5。必须逐级满足条件，条件满足时可能按同一判定连升多级。合计最大 290。

速度判定使用每题答题时间除以基准时间的比率。基准时间为 `第一格的连击时限 + max(0, 作答格数 − 1) × 普通格时限`。比率的中位数只从该技能的一次答对题计算。

| 星 | 条件 |
| --- | --- |
| ☆1 | 已掌握 |
| ☆2 | 最近 20 题齐备，一次答对率 0.9 以上 |
| ☆3 | 最近 10 题齐备，其中 5 题以上一次答对，时间比率中位数 1 以下 |
| ☆4 | 最近 3 题全部一次答对，且各题日期距 ☆3 获得日 7 天以上 |
| ☆5 | 最近 20 题齐备，一次答对率 0.95 以上，时间比率中位数 0.6 以下 |

☆4 的 3 题不必同一天。星星不会因通常游玩或休息而减少，删除技能记录与全部重置会清掉。说明画面显示下一颗星的条件、当前值、解题数和最快解题时间。

### 6.4 生锈

已掌握且距最后一次一次答对超过 `21 × 86400000` ms 的技能为候选，按久远顺序最多 3 个显示「锈」。没有一次答对时间时，依次参照实力测试的赋予时间、掌握时间。

对生锈技能一次答对 1 题即擦亮，保持星星并去掉标记。擦亮后其它旧技能可能成为显示对象。用于我的等级的复习和「擦亮」任务。

### 6.5 技能的记录删除

长按有记录的技能 600ms，或聚焦后按 Delete，打开确认框。按住时移动超过 10px 则中止长按。

确定后删除该技能以及直接、间接依赖它的技能的记录和星星。所选技能在前置仍满足时回到新技能，前提不齐时回到未解锁。历史、复习、累计统计、奖杯、收藏、实力测试已测状态保留。

## 7. 坚持玩的机制

### 7.1 历史・日历・登录奖励

基础结算保存历史，加时结束后更新同一条历史的得分、追加答对数、差一点、多巴。最多保存 3000 条。日历显示每日最高分和练习次数，点日期打开详情。可以翻到过去的月份，不能翻到未来。

连续天数从今天起算，今天还没练则从昨天起算。同时显示最长记录和登录贴纸张数。练习日与登录日是分开的，只打开标题不算练习日。

登录奖励按设备日期每天一次。以星、心、花、音符、四叶草、小红花、皇冠的 7 天周期领取贴纸。夹入未补签的缺席日会重新从第 1 天数起。贴纸在打开显示的时刻即视为领取，关闭或刷新都不会在同日重复领取。

### 7.2 补签锤

一把锤子可以把没玩的 1 天设为补签，衔接练习和登录的连续。不会把那天加进练习天数，也不会补发那天的贴纸。初始持有 1 把，上限 3 把。

当最后一次练习日在最近 7 天内、到昨天为止的空缺日都能用持有数覆盖、且能保住 2 天以上连续时，标题会建议每天使用一次。拒绝的当天不再提议。使用后在日历上盖补签章。使用记录最多 50 条。

### 7.3 每日任务

根据设备日期和当天选择时刻的记录，确定简单的 2 个和费事的 1 个并保存。同一天即使更改设置也不会重选。日期变更后的更新处理切换到新列表。候选是固定 11 种加 1 种与生锈联动的任务。

| 名额 | 候选与达成条件 |
| --- | --- |
| 简单 | 完成 1 次、5 连击、一次答对 5 题、复习 1 题、新技能 1 题 |
| 费事的 | 进入加时挑战、加时挑战答对 5 题、20 连击、完成 2 次、按年级完成 1 次、练习中的技能 10 题、指定技能一次答对 3 题 |

没有复习・新技能对象时排除相应候选。加时相关要求最近 5 条历史中有加时记录；20 连击要求 `题数 × 平均作答格数 >= 26`；练习中 10 题要求已测且有未掌握候选。同日不叠加相同指标的任务。

耗时筛选模型按 1 次 `(题数 × 18 + 预计有加时 90 + 30) / 60` 分钟计。一次答对 5 题预计 `ceil(5 / (题数 × 0.7))` 次，练习中 10 题 `ceil(10 / (题数 × 0.6))` 次，20 连击预计 2 次。复习按最多 10 题计算，把各模式间可共同达成的项叠加，选择合计 15 分钟以内的组合。这只是估计，不限制实际耗时。

擦亮候选在当天有生锈技能、由日期派生的随机数小于 0.5、且最近 7 天提示次数不足 2 时成为选择对象。可以从标题开始该技能的练习，达成需要同一技能 3 题一次答对。与擦掉锈本身的 1 题条件不同。

进度在游玩中累加，达成时在画面上端提示。复习也计入共通的完成・一次答对・连击条件。3 个全部达成时当天一次性获得 1 把锤子，并在日历上标记。已达上限时只演出，奖励不结转到以后。

### 7.5 与之前比较

基础结算中，把同一技能较此前记录有进步的项目以「进步啦！」最多显示 3 行。本次与比较对象双方都需要 3 题以上。比较对象为：上次练习日、21 天前内的最近一天、最初解的 3 题。同日内的过去场次不作为比较对象。

解答时间按每作答格平均比较，显示换算为本次平均格数的每题秒数。时间缩短 10% 以上或一次答对率提升 10 个百分点以上的项目为候选。每个技能选出最大的 1 项改善，再按改善幅度排序显示。没有改善就不显示。实力测试、演示和停止成长记录的验证 URL 不参与。

### 7.6 时间胶囊

每个技能保存的最初 3 题中，从已掌握、距解题时刻超过 `30 × 86400000` ms 的未使用题里选最旧的。

通常我的等级、按年级、练习的基础集在 4 题以上时，替换从 0 数起 `max(1, min(N−2, floor(N/2)))` 位置的一题。实力测试、复习、加时挑战、演示、停止成长记录的验证 URL 不参与。每天最多 1 题，由于在预告结束时保存日期，其后即使中断同日也不会再次出现。题目完成时标记为已使用。

通过信封预告和橙色边框让人知道是过去的题。比较时本次时间不足过去的 0.95 倍显示时间缩短，否则差一次次数减少，两者都没有时显示再次解出与日期。恰好缩短 5% 不算时间缩短。

### 7.7 错因归因

答错时按「这一位错在哪里」归类并计数，供成长页展示。**只在按下的数字能证明某个错法时才归类**，其余一律记为未归类。可识别的错法有五类：

| 内部名 | 含义 |
| --- | --- |
| `carry` | 忘了进位（竖式与横式各一种判据） |
| `borrowZero` | 退位时借位穿过了 0 |
| `borrowMiss` | 该退位却按「大数减小数」读了 |
| `swap` | 把积的十位数字写进了个位 |
| `wrongFactor` | 用乘数的另一位相乘 |

判定所需的材料来自题目生成器已经产出的步骤对象（`help.ids` 的参照格、`help.text` 的算式、减法退位链 `marks`、以及题目自身的列数），因此**不需要孩子额外输入任何东西**。

只有列结构生成器（加减竖式、乘法、除法）产出的是列算式，其余技能（分数、取整、倍数、乘法口诀等）的提示是概念说明，没有可复算的算式，那些步骤**按设计不归类**。实测覆盖率见 `docs/DESIGN.md`。

计数按技能保存为 `progress.skills[id].slips`（各错法次数，含未归类），并按天保存为 `slipDays`，**只保留最近 30 天**。成长页的「哪里卡住」取近 30 天合计的前三名，并显示「已归因 a 次 / 共 b 次」——**这个覆盖率是必须显示的**，否则只列三个错因会让报告显得比实际更完整。

## 8. 多巴奇与演出・声音

多巴奇原则上不说话。造型基准见 `docs/dopakichi.svg`。有大大的横耳朵、横向宽阔的圆头、奶油色的脸和肚子、双圆眼睛、细手臂和蓝色的脚。基本色为粉 `#FF97BF`、奶油 `#FFF3E4`、耳内侧 `#FFE6F0`、蓝 `#2F79F7`、轮廓 `#000000`。

输入的数字用空着的手搬运。左右手可以分别搬运不同数字，判定与搬运分开，不等待下一次输入。中途答对・最终答对用跳跃、拍手、旋转等，答错时先瘫倒再恢复。错答表演共 10 种，前段 4 种、中段 8 种、强度 0.6 以上 10 种，避开紧邻上一次选择。

设基础题号从 0 记为 `i`、题数为 `N`，演出强度为 `E = 0.08 + 0.92 × (i/(N−1))^1.3`。只有 1 题时 `E = 1`。加时按完成数 `k`：`tier = floor(k/3)`、`E = 1 + min(0.5, tier × 0.1)`。无尽按波次 `w`：`E = 1 + 0.6 × (1 − e^(−(w−1)/9))`。

演出强度只表示「此刻多热闹」，等级 `L` 表示「爬到第几档」，两者分开。基础与加时取 `L = min(16, round(E × 10))`，因此基础集在 1〜10 档内走完，加时能爬到 15 档。无尽不接受 `E` 推出的值，直接取 `tier = min(16, 10 + floor((w−1)/2))`——`E` 在无尽模式里从第一题起就很高，用它推等级会把阶梯一端钉死。

| 15 | 多巴奇的聚光池，弹跳幅度增大，礼花种类加厚 |

第 1、2、7 档没有内容，即这几档之间画面不变。第 16 档的节拍闪光有非零底值，因此静音或音乐未开始播放时也看得见。

强度叠加背景、小红花等答对标记、彩纸・星星・烟花・硬币、观众、行进、逼近、灯饰、晃动；观众人数与礼花的种类密度按**等级**而非强度决定。谢幕从巨型多巴奇、烟花大会、火箭、游行中选择，最后显示 100 分。保持输入与键盘的布局以及竖式的位对应。

音乐与音效用 Web Audio API 合成，不加载外部录音素材。基础的马林巴进行曲之外，有 8 比特、祭典太鼓、铜管乐队、电子乐共 5 曲。用振荡器、噪声、滤波与残响等逐级叠加打击乐、低音、和弦与旋律；每首曲子与默认曲风都在第 11、13、15 档各再加一层（碎拍、hook 下方的对位线、全乐队跟上 hook）。

基础 tempo 为 `112 + min(1, E) × 16` BPM，通常开头 113.28 BPM、最后 128 BPM。最后一题按基准升 2 个半音。加时为 `134 + tier × 5` BPM，调性按基准升 `2 + min(tier, 5)` 个半音。转调有上限，tempo 没有该公式之外的固定上限。

用声音辅助按键、数字落位、答对、答错、多巴节点、计时器等，音程与曲子和弦同步。声音开始利用浏览器要求的用户操作。背景用 WebGL，不可用或上下文丢失时切换到 CSS 背景。

## 9. 设置与无障碍

| 设置 | 内容与初始值 |
| --- | --- |
| 题目数量 | 6、10、14 道。默认 10 道 |
| 语言 | 中文（默认）、English、日本語。见 1.1 |
| 声音 | 开／关。默认开。也可从练习画面的静音按钮切换 |
| 音量 | 0〜100%。默认 80% |
| 动效强度 | 0〜100%。未设置时跟随系统的减少动态设置（0%），否则 100% |
| 自动演示 | 自动操作显示一圈 |
| 全部重置 | 确认 2 次后初始化设备上的数据 |

动效强度反映在粒子量、晃动、闪光、背景、观众、多巴奇的大动作上。0% 时停止主要的移动、晃动、闪光，引导也变为静止姿势。但不是停止全部绘制的功能，通常画面的呼吸和少量粒子仍保留。调整数值时可在设置画面确认反应。判定与得分规则不变。

Escape 在打开的对话框上关闭它，在标题以外的画面打开「返回标题？」确认。初始焦点在「继续」，确认期间暂停输入、基础经过时间、加时与连击时限、每题计时。到中断为止完成的题目的熟练度等保留。基础结算前不生成完成历史。演示中的 Escape 是结束演示。

准备了按钮的可访问名称、焦点显示、数字以外的标签、引导内的焦点循环。不保证仅靠屏幕阅读器完成全部游玩或所有设备上的操作性。

高度 700px 以下时调整题目纸・演出区域・留白，把键盘最下排收进画面。矮屏也保持键高 48px。

全部重置第一次显示「全部重置」将删除的内容，第二次以「真的要删除吗？」确认不可恢复。两者的初始焦点都在「取消」。取消、Escape、点击背景都不会删除。第二次确定后删除所有以 `dopa-drill` 为前缀的保存键，丢弃内存缓存并重新加载。无关的键保留。

设置・历史・熟练度・星星・成长记录・奖杯・收藏选择・贴纸・任务・道具・首次引导状态都会初始化。重新启动时会重新生成首次引导和初始道具等。即使浏览器拒绝删除，处理也不会异常退出，但不保证已保存数据确实被清除。

## 10. 保存与隐私

保存位置是浏览器的 localStorage，键为 `dopa-drill:v1`，数据版本为 1。没有输入姓名等个人信息的栏位，应用不会向服务器发送学习记录。没有广告、外部统计、排行榜和设备间同步。从发布服务器取得游戏的静态文件运行。

保存区不可用、读取失败或 JSON 损坏时，以初始状态启动；保存失败时当前游戏也会继续。浏览器的数据清除、存储限制、换浏览器或来源使用时，记录无法继承。

| 记录 | 内容・上限 |
| --- | --- |
| 设置・引导 | 题数、声音、音量、动效、语言、引导已显示 |
| 完成历史 | 最多 3000 条。日期、模式、得分、答对、差一点、基础用时、多巴、加时 |
| 技能 | 最近 6 题的一次答对、最近 24 签名、最近 30 题的时间・格数・错答・日期、最近 60 天的汇总、最初的 3 道题本身、最后一次答对・掌握时间、星星 |
| 复习 | 最多 40 道题本身 |
| 累计统计 | 完成题数・格数・一次答对・错答、基础完成与模式、基础用时、最大多巴、加时、最大连击、复习、练习日、擦亮次数、对比・胶囊 |
| 坚持・奖励 | 贴纸、登录日、补签日、锤子、任务、已获奖杯、演出选择 |

单题解答时间从接受输入到最后一次答对输入为止，不含题目间的演出和确认对话框。累计的题数・格数・错答在题目完成时加算，因此中途放弃的未完成题操作不参与统计。

统计尚不存在的存档会从历史初始化可得的值。过去的格数、最大连击等历史中没有的值从 0 开始测量。验证 URL 不是整体停止保存的功能，具体差异见下一章。

### 11.2 启动与测试

从仓库根目录静态托管，例如：

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

在显示的地址打开 `/app/`。因为使用 ES Modules，请通过 HTTP 访问而不是直接打开 HTML 文件。Windows 中 `python -m http.server` 可能以 `text/plain` 返回 `.js` 导致模块无法加载，此时使用：

```sh
node tools/serve.mjs 8000 app
```

Node 测试运行：

```sh
node --test tests/*.test.mjs
```

产品测试为 `tests/app_*.test.mjs` 的 18 文件・143 项，即仓库内的全部测试。在只显示文件单位件数的环境中，可加 `--experimental-test-isolation=none` 汇总单项测试。

### 11.3 验证用 URL 参数

如 `/app/?count=6&seed=123` 指定。

| 参数 | 行为 |
| --- | --- |
| `count=6`、`count=10`、`count=14` | 选择启动时的题数 |
| `seed=<数值>` | 固定题目选择・生成等使用的随机数。不固定全部视觉效果的随机数 |
| `extra=<秒>` | 替换加时默认 90 秒。开始时 900ms 的加算通用 |
| `skill=<技能ID>` | 把通常的选题替换为该技能。与复习或固定模板并用时存在选择处理的优先顺序 |
| `demo` | 从我的等级入口开始固定模板的基础集。首题为 27＋35。不进行自动操作 |
| `capture` | 收集声音事件的验证路径。抑制通常的实况声音输出与自动引导、标题奖励通知等 |

`skill` 与固定模板的练习停止通常的解答时间・成长统计・任务，但完成历史与复习会保存。`skill` 下出题计划为实力测试时，计划侧的掌握赋予与测完保存也会运作。奖杯判定在 `skill` 和 `capture` 下停止，仅 `demo` 不停止。`capture` 下通常的进度・历史・统计保存继续。请不要把这些当作不留记录的练习功能。
